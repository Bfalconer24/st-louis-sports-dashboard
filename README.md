# St. Louis Sports Dashboard

## Purpose

This project is to help me learn Python by building a sports analytics dashboard that retrieves sports data from APIs, stores it in SQLite, and will eventually display analytics and visualizations.

## Technologies

- Python
- Requests
- SQLite
- Git

## Current Features

- Fetch team data from TheSportsDB API
- Fetch event data from TheSportsDB API
- Store teams in SQLite
- Store events in SQLite
- View stored records

## Project Structure

api_fetch.py
database_teams.py
database_events.py
data_table.py
view_database.py
sports.db
